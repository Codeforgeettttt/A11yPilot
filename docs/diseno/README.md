# Identidad visual y sistema de diseño · A11yPilot

Esta carpeta reúne la documentación visual del proyecto para la asignatura **Ingeniería Web II**.

## Manual de identidad visual

**Documento original:** [📄 Consultar manual de identidad visual de A11yPilot (PDF, 10 páginas)](./LOGO%20A11YPILOT.pdf). El archivo original ya está disponible en esta carpeta.

El documento contiene:

1. **Logotipo oficial** y símbolo de accesibilidad.
2. **Jerarquía tipográfica:** Intro Rust para títulos, Archivo Black para subtítulos y Nunito para texto.
3. **Propuesta de dashboard** con navegación, indicadores y análisis recientes.
4. **Alertas accesibles**, distinguiendo éxito, advertencia, error e información mediante icono y texto.
5. **Tarjetas** para sitios registrados y seguimiento de análisis.
6. **Formulario** para registrar URLs públicas autorizadas.
7. **Botones y foco de teclado** con ejemplos de estados visuales.
8. **Usos del logotipo** y área de respeto.
9. **Variantes cromáticas** de la identidad.
10. **Paleta de marca y degradado**.

### Colores de marca

| Color | Código | Uso propuesto |
| --- | --- | --- |
| Turquesa | `#43C6C8` | Acciones y acentos |
| Azul marino | `#0B1F3A` | Navegación y contraste |
| Azul profundo | `#0E243C` | Texto y contornos |
| Blanco | `#FFFFFF` | Fondos y superficies |

> **Importante:** los ejemplos del manual representan decisiones y propuestas visuales. Las menciones a Playwright y axe-core ilustran la evolución prevista del sistema; la primera entrega de A11yPilot utiliza análisis simulados. El manual no constituye evidencia de que todas sus pantallas estén implementadas exactamente como aparecen.
